# 三菱 PLC (FX3U) 序列埠監控與控制系統 (C# Windows Forms)
## 技術士技能檢定機電整合丙級術科測試 — 第三站自動化整合版

本專案為一套使用 **C# (.NET 8.0-windows)** 開發的 Windows Forms 應用程式，專為**機電整合實務**、**技術士技能檢定機電整合丙級術科測試（第三站：凸輪垂直升降與旋轉取放料機構）**與**三菱 FX3U PLC** 設計。支援以 **Visual Studio 2026 / 2022** 開啟與維護，透過電腦序列埠 (Serial Port / USB-to-RS422 程式通訊口) 實現接點狀態即時輪詢監控、強制輸出控制、完整 **機台控制面板 (HMI) 虛擬操作總覽**、**I/O 配置對照表**、一鍵執行 **「機電丙三啟動」** 自動化檢定流程，以及三色指示燈 **「跑馬燈測試」**。

---

## 支援環境與通訊規格

- **開發工具**：Visual Studio 2026 / Visual Studio 2022
- **執行平台**：.NET 8.0-windows (x64)
- **通訊介面規格**：
  - **傳輸速率 (Baud Rate)**: `9600 bps`
  - **資料位元 (Data Bits)**: `7`
  - **同位檢查 (Parity)**: `Even` (偶同位)
  - **停止位元 (Stop Bits)**: `1`
  - **流控 (Handshake)**: `None`

## 機電整合丙級第三站：核心功能與動作說明

點擊視窗頂部醒目的紫色按鈕 **【▶ 機電丙三啟動】**，即可執行技術士技能檢定機電整合丙級第三站之標準動作程序：

### (一) 待機狀態
- 機構回到機械原點：
  - 推料缸 A 在後位（`X1: a0`）。
  - 馬達 M 停止。
  - 垂直升降凸輪組件 D 在上位（`X6: d0`）。
  - 真空吸盤 C 不吸（`Y5: OFF`、`Y6: OFF`）。
  - 旋轉缸 B 回到 0° 原點（`X2: b0`）。
- 待機指示燈 **GL (Y17) 點亮**，運轉指示燈 **RL (Y15) 熄滅**，系統未啟動任何功能。

### (二) 工作模式動作功能 (選擇開關 COS1 右切至工作模式 `X13 = ON`)

1. **單一循環與標準取放步序 (COS2 切換至中位「單一循環」)**：
   - 按下 `ST/RST` (X16) 鈕，運轉燈 **RL (Y15) 亮**，待機燈 **GL (Y17) 滅**，啟動單一循環：
   - **Step 1（推料與 X10 感測）**：推料缸 A 推出料件至前端治具（`Y0 ON`，檢知 `X0: a1`），推出過程中感測器 `s1 (X10)` 感測料件次數。
     - **若 X10 未感應到料件 (0 次，缺料)**：推料缸立即縮回後位 `X1: a0`，流程結束回到待機狀態，待機燈 **GL 亮**，運轉燈 **RL 滅**。
     - **若 X10 僅感應到 1 次**：迴轉缸轉至 **+90°**（`Y3: B1 ON`，檢知 `X3: b1`）。
     - **若 X10 感測到 2 次**：迴轉缸轉至 **-90°**（`Y4: B2 ON`，檢知 `X4: b2`）。
   - **Step 2（迴轉定位）**：迴轉缸依 X10 感測次數轉至取料方向（-90° 或 +90°）。
   - **Step 3（馬達下降）**：垂直升降模組馬達旋轉 R1 (`Y7 ON`) 下降至下端點 `X7: d1` 取料位。遇到端點立即煞停 1 秒鐘校驗位置；確認到位後接續動作。
   - **Step 4（吸盤吸料）**：真空吸盤吸 `C+ (Y5 ON)`，真空壓力開關 `ps1 (X5)` 負壓建立。
   - **Step 5（推料缸後退）**：吸盤吸料完成後，**推料缸 A 縮回後端點 a0**（`Y0 OFF`，檢知 `X1: a0`）。
   - **Step 6（馬達上升）**：垂直升降模組馬達旋轉 R1 (`Y7 ON`) 上升至上端點 `X6: d0` 吸持料件。遇到端點立即煞停 1 秒鐘校驗位置。
   - **Step 7（迴轉缸轉至 0° 且保持氣壓）**：
     - **氣壓支撐機制**：因機台無轉至 0° 輔助定位機構，轉至 0° 時**同時啟動 Y3 與 Y4**，且 **Y3、Y4 訊號持續輸出，直到料件排出（吸盤放料完成）後才可停止輸出**，以避免迴轉缸因無氣壓支撐而偏移位置。
     - **1 秒定位等待**：轉到 0° 需等待 1 秒鐘後，才可進行下一動作（此時 Y3、Y4 持續輸出），以保證確實轉至 0°（檢知 `X2: b0`）。
   - **Step 8（馬達下降至排料位）**：升降模組馬達旋轉 R1 下降至排料斜坡（`X7: d1`），此時 Y3、Y4 仍維持氣壓支撐。
   - **Step 9（吸盤放料與氣壓解除）**：真空吸盤放料 `C- (Y6 ON)` 破真空，料件由出料斜坡滑下排出；**料件排出後才關閉 Y3、Y4**（停止氣壓輸出）。
   - **Step 10（馬達上升）**：垂直升降模組馬達旋轉 R1 上升回上位 `X6: d0`。完成單一料件取放流程，回到待機狀態（**GL 亮**，**RL 滅**）。

2. **連續循環 (COS2 右切至「連續循環」`X15 = ON`)**：
   - 按下 `ST/RST` 鈕，執行連續 4 個工件循環處理。
   - **缺料智能暫停與人工補料續行**：
     - 若推料缸推出料件後 **X10 未感應到料件**，推料缸立即後退縮回 `a0`，並**暫停運轉（保留已做料件數，不清除 PieceCount）**。
     - 系統於日誌提示「缺料暫停，請補充料件並按下 ST 繼續」。
     - 人工於料匣補充料件並按下 `ST/RST` 鈕後，系統自動解除暫停並繼續執行，直至完成全部 4 個料件後回到待機狀態（**GL 亮**，**RL 滅**）。

3. **調機功能 (COS2 左切至「指定功能」`X14 = ON`)**：
   - 機械運轉前選擇開關切至「指定功能」，按下 `ST/RST` 鈕後動作於流程圖中記號 **「#」** 步序暫停：
     - **暫停點 #1**：升降模組馬達下降 R1 取料完成後，暫停於真空吸盤吸 C+ 之前。
     - 需再次壓按 `ST/RST` 鈕，才繼續執行至下一個記號 **「#」**。
     - **暫停點 #2**：升降模組馬達下降 R1 排料位完成後，暫停於吸盤放料 C- 之前。
     - 再次壓按 `ST/RST` 鈕，繼續完成吸盤放料、復歸上位與推料缸縮回。

### (三) 緊急停止功能 (EMS `X17` 壓扣開關 - NC 接點)
- 當按下緊急停止鈕 EMS（`X17` 斷路 / OFF）時：
  - 系統立即停止運轉，所有電磁閥、馬達全面斷電。
  - **重要安全保護**：真空吸盤 C+ 若有吸取料件，**繼續保持吸持狀態，絕對不掉落**！
  - 在解除緊急停止鈕 EMS（`X17` 恢復導通 / ON）之前，壓按 `ST/RST` 鈕無效。

### (四) 復歸模式動作功能 (COS1 左切至復歸模式 `X13 = OFF`)
- 解除 EMS 後，選擇開關 COS1 切至「復歸模式」，按下 `ST/RST` 鈕執行自動復歸。
- 復歸指示燈 **YL (Y16) 以 0.5 秒亮 / 0.5 秒滅持續閃爍 3 秒以上**。
- 機構依序回原點位置：升降回上位 d0、迴轉缸回 0° (同時啟動 Y3 與 Y4 計時 1 秒)、推料缸縮回後位 a0，過程中防止任何碰撞干涉，回到機械原點後自動停止。

## 跑馬燈測試功能 (Marquee Test) 與狀態恢復

主視窗頂端操作列與 HMI 控制面板三色指示燈區皆提供 **【★ 跑馬燈測試】** 按鈕：
- **觸發動作**：按下按鈕後，依序執行三色指示燈之循環點亮：
  1. **黃燈、綠燈滅，同時紅燈亮 1 秒**（`Y16=OFF, Y17=OFF, Y15=ON` -> 計時 1.0 秒）
  2. **綠燈、紅燈滅，同時黃燈亮 1 秒**（`Y17=OFF, Y15=OFF, Y16=ON` -> 計時 1.0 秒）
  3. **紅燈、黃燈滅，同時綠燈亮 1 秒**（`Y15=OFF, Y16=OFF, Y17=ON` -> 計時 1.0 秒）
- **循環次數**：連續執行 **3 個循環**。
- **測試完成**：3 個循環結束後，3 個燈短暫全滅（`Y15=OFF, Y16=OFF, Y17=OFF`）。
- **狀態自動恢復**：測試完成或手動中斷後，**立即依當前程式與機台狀況自動恢復相應燈號**：
  - 機台處於**待機狀態**時：自動點亮待機燈 **GL (Y17)**，熄滅 RL 與 YL。
  - 機台處於**運轉狀態**時：自動點亮運轉燈 **RL (Y15)**，熄滅 GL 與 YL。
- **手動停止**：測試執行期間按鈕變換為紅色 **【⏹ 停止跑馬燈】**，隨時再次點擊可立即中斷測試並恢復對應燈號。

## 關鍵技術突破與介面優化

### 1. 垂直升降馬達極限防衝自停聯鎖（解決通訊延遲跑過頭）
- **問題起因**：序列埠在 9600 bps 下，常態輪詢與排程佇列易存在數百毫秒的時間差。升降模組馬達 Y7 運轉至上端點 `d0 (X6)` 或下端點 `d1 (X7)` 時，若由主流程等待輪詢後再發送停止命令，馬達常因延遲繼續旋轉而離開端點，造成嚴重「跑過頭」現象。
- **解決方案**：
  - 於 `PlcService` 與 `MechatronicsLevel3Service` 導入 `RunMotorToLimitAsync` 與 `ArmMotorAutoStop` 聯鎖機制。
  - **極速輪詢**：馬達運轉期間，輪詢週期自動縮減至 **25ms** 極速監控。
  - **底層毫秒級直接切斷**：通訊緒在解碼收到 X 輸入接點狀態的當下瞬間，一旦命中目標極限端點，立即以最高優先權於底層直接發送 Y7 斷電指令（0ms 等待），使馬達精準且即時煞停於端點上，徹底杜絕衝過頭！

### 2. 連線狀態文字與頂端按鈕排版優化
- 將 **【▶ 機電丙三啟動】** 按鈕右移至 `X = 1200`，使左側 `● 已連線 (COMx)` 狀態標籤即便顯示長文字也保有寬裕間隔。
- 將 **【★ 跑馬燈測試】** 按鈕移至 **【▶ 機電丙三啟動】** 按鈕正下方（上下堆疊排列，尺寸統一為 170x26），介面簡潔大方且徹底解決相互遮擋問題。

### 3. 【面板】金色標籤左移優化
- 在輸入 (X13~X17) 與輸出 (Y15~Y17) 卡片中，採用 `TextRenderer.MeasureText` 動態量測標題文字長度，將金色 `【面板】` 標籤緊鄰標題右側（`X ≈ 110px`）。
- 輸出卡片右側之 `ON` / `OFF` 強制控制按鈕位於 `X = 234px`，兩者之間保有近 80px 的寬敞餘裕，徹底解決了原本 `【面板】` 覆蓋 `ON` 按鈕的困擾。

## 通訊即時日誌：極簡步序模式 (Log Filter)

依使用者需求：「**Log 的資訊太多，僅需記錄機電丙狀態，看目前跑到哪個步驟**」：
- 下方通訊日誌工具列預設勾選 **「☑ 僅顯示動作步驟 (精簡)」**。
- **過濾機制**：
  - 自動徹底隱藏每 200ms 不斷收發的常態輪詢原文字串 (`讀取 Y0~Y17`、`讀取 X0~X17`) 與強制輸出的底層 TX/RX 封包。
  - 專注輸出乾淨高亮的機台當前狀態與執行步序：
    ```text
    [10:15:00] [機電丙三啟動] 運轉模式：單一循環 (1 個工件)
    [10:15:01] [待機狀態] 機構已確認回到機械原點
    [10:15:02] [步驟 1/8] 推料氣壓缸 A 伸出 (Y0 ON)，推送料件至前端治具
    [10:15:03] [步驟 2/8] 感測器 s1 (X10) 判別凹槽偏置方向：左側 (s1=ON)
    [10:15:04] [步驟 3/8] 迴轉缸轉至 +90° 取料方向 (Y3: B1 ON)
    [10:15:05] [步驟 4/8] 升降模組馬達旋轉 R1 (Y7 ON) 下降至下端點 d1 取料
    [10:15:06] [步驟 5/8] 真空吸盤吸 C+ (Y5 ON)，負壓建立 (X5: ps1)
    [10:15:07] [步驟 6/8] 升降模組馬達旋轉 R1 (Y7 ON) 上升回上端點 d0 (吸持料件)
    [10:15:08] [步驟 7/8] 迴轉缸轉至 0° 排料位 (同時啟動 Y3 與 Y4，計時 1 秒定位)
    [10:15:09] [步驟 8/8] 真空吸盤放 C- (Y6 ON)，料件由出料斜坡排料，推料缸縮回 a0
    [10:15:10] [排料完成] 第 1 個料件成功排料，機構回到機械原點待機
    [10:15:11] [完成] 單一循環 (1 個工件) 執行完畢，回到待機狀態 (GL 亮)
    ```
- 若調機功能啟動，即時提示：`[調機暫停] #1 升降模組下降完成，暫停於吸盤吸取前 (按 ST/RST 繼續)`。
- 若跑馬燈測試啟動，即時提示：`[跑馬燈] 循環 1/3：黃/綠燈滅，紅燈亮 (計時 1 秒)`。
- 若需要進行底層封包通訊診斷，只需取消勾選「僅顯示動作步驟 (精簡)」，即可恢復檢視 TX/RX 原始 Hex 封包。

## 控制面板規格說明

| 名稱 | 說明 | 類型 | 對應 I/O |
| :--- | :--- | :--- | :---: |
| **ST/RST** | 在工作模式做為啟動用，而在復歸模式時做為復歸用 | 復歸式按鈕開關 | **X16** |
| **EMS** | 作為緊急停止之用 (需使用 NC 接點，導通為正常，斷路為急停) | 壓扣式按鈕開關 | **X17** |
| **COS1** | 作為選擇「復歸模式」/「工作模式」之用 | 二段切換式選擇開關 | **X13** |
| **COS2** | 作為選擇「指定功能」/「單一循環」/「連續循環」之用 | 三段切換式選擇開關 | **X14 (左), X15 (右)** |
| **RL** | 紅色指示燈，運轉時亮，待機時滅，代表運轉燈 | 指示燈 | **Y15** |
| **GL** | 綠色指示燈，待機時亮，運轉時滅，代表待機燈 | 指示燈 | **Y17** |
| **YL** | 黃色指示燈，復歸中 0.5 秒亮/0.5 秒滅閃爍，代表復歸燈 | 指示燈 | **Y16** |
